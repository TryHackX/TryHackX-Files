# Contributing

Bug reports, reproducible test cases and feature discussions are welcome through the repository's
issue tracker. Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md),
not in a public issue.

TryHackX Files uses a dual-licensing model. To preserve the project's ability to offer commercial
licenses, do not submit a pull request containing code before agreeing contribution terms with the
project owner. A contributor agreement or equivalent written permission may be required. An
unsolicited code pull request may be closed without review.

Opening an issue or discussing a possible change does not transfer copyright and does not grant a
commercial-use license. See [LICENSING.md](LICENSING.md) for the project licensing overview.
